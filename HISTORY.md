# History

One Gateway was originally derived from [One API](https://github.com/songquanpeng/one-api)
by JustSong and other contributors. The repository keeps One API's full commit
history. Upstream work in this repository ends at commit `8df4a26`
(2025-02-21); One Gateway's own work starts at `397db3d` (2026-09-23).

The inherited upstream release tags were removed so that One Gateway's
version line stays unambiguous; the local tag `upstream-one-api-base` marks
the last upstream commit. Attribution and licensing are described in
[`NOTICE`](NOTICE) and [`LICENSE.upstream`](LICENSE.upstream).
